    LogisticClient.__init__ fits imputer + scaler on X_train only.
    client_auroc() calls client._preprocess(X_test) which applies the
    already-fitted (train-only) transforms. X_test is never seen during
    imputer.fit() or scaler.fit(). -> CONFIRMED (by code inspection of
    federated/fedavg.py lines 52-53 and run_e6_fairness.py).

    Feature set: 22 numeric columns from cimas_htn_landmark_6m.parquet
    (same EXCLUDE_COLS applied to all conditions).
    Per-provider imputer (median) + StandardScaler fitted on each provider's
    own training rows. Same split -> same fit -> identical preprocessing
    across conditions for any given (provider, seed). -> CONFIRMED.

    n_local_epochs = 5 for all conditions.
    lr = 0.02 for all conditions.
    class_weight = 'balanced' for all conditions.
    mu = 0.0 (FedAvg, no proximal term) for all conditions.
    -> CONFIRMED. make_clients() uses identical hyperparameters.

TERMINOLOGY NOTE
========================================================================
  This experiment measures provider-level AUROC disparity (macro-
  average, worst-provider, 10th-percentile, IQR across K=23 pharmacy
  providers). It does not measure individual fairness, demographic
  fairness, or equitable outcomes for patient subgroups. The term
  'fairness' in the figure/script names refers to performance equity
  across data contributors (provider-level), not to protected-attribute
  fairness. Language in any manuscript section should be scoped
  accordingly.
